ระบบสั่งอาหารล่วงหน้าโรงอาหาร Moodeng999 สามาชิกทีมและสิ่งที่อยากเรียนรู้ นายกรวิชญ์ ยงค์เพ็ชร Develop A (API/Server) อยากเรียนรู้การพัฒนา API การรับส่งข้อมูลระหว่าง Frontend และ Backend และการจัดการข้อผิดพลาดของระบบ นายกันตพงศ์ แสนบุตร -Develop B มีหน้าที่ทำ (Database) อยากเรียนรู้การออกแบบฐานข้อมูล การทดสอบ API ด้วย Postman และการใช้ Github ทำงานร่วมกันเป็นทีม เป้าหมายของโครงงาน พัฒนาระบบสั่งอาหารล่วงหน้าโรงอาหาร เพื่อให้นักศึกษาสั่งอาหรได้สดวกและประหยัดเวลา ข้อตกลงการทำงาน แบ่งหน้าที่ให้ชัดเจนช่วยกันตรวจสอยและทดสอบระบบ บันทึกการเปลี่ยนแปลงโค้ดผ่าน Github
